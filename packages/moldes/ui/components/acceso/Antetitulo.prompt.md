El rótulo `§ · PALABRA` que va arriba de un título o de un bloque.

```jsx
<Antetitulo texto={t('auth.totp.eyebrow')} />   // § · VERIFICACIÓN
<Antetitulo texto="Por persona" tono="apagado" />
```

- El archivo de idioma trae la palabra sola; las mayúsculas y el `§ ·` los pone el componente.
- La pantalla de entrada (P1) no lleva antetítulo.
