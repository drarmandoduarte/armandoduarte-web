Botón de un solo icono para barras de herramientas densas (agenda, ficha, bandeja de WhatsApp).

```jsx
<IconButton icon="mic" label="Dictar" variant="solid" />
<IconButton icon="chevron-left" label="Semana anterior" />
<IconButton icon="filter" label="Filtrar" active />
```

- `label` nunca es opcional: es el `aria-label` y el tooltip.
- Cajas de 28 / 32 / 40px con iconos de 14 / 16 / 20px.
